# AI Journey · Kunxiang Shen

Curated conversations I've had with AI tools, and an automatically generated summary of what I asked and what I learned. It powers the **Server Archive** room on my site: https://keloshen.github.io

- `chats/` · one Markdown file per conversation (curated highlights, not full logs)
- `summary.json` · generated by a GitHub Action whenever `chats/` changes; the website reads it
- `scripts/summarize.py` · computes stats and asks an LLM for a short summary in EN / ZH / DE

## Adding a conversation

1. Copy `chats/_TEMPLATE.md` to `chats/YYYY-MM-DD-short-name.md`.
2. Fill in the front matter (title, date, tool, topics) and the sections. Keep the best exchanges, cut the rest.
3. Go through the **redaction checklist** below.
4. Set `draft: false` (or delete the line) and push. The Action updates `summary.json` within a minute or two, and the website picks it up.

Files starting with `_` and files with `draft: true` are ignored.

## Redaction checklist (this repo is public)

Before publishing, remove or replace:

- [ ] Phone numbers, home address, ID / student numbers, dates of birth
- [ ] API keys, tokens, passwords, internal URLs, server names, IPs
- [ ] Company-internal information (code, project names, customers, metrics) from internships or employers
- [ ] Names and personal details of other people (use "a colleague", "my supervisor")
- [ ] Anything you wouldn't want a future employer to read

## One-time setup

1. **Pages** · Settings → Pages → Source: *Deploy from a branch* → `main` / `(root)` → Save.
   `summary.json` is then served at `https://keloshen.github.io/ai-journey/summary.json`, on the same domain as the website.
2. **AI summary (optional)** · Settings → Secrets and variables → Actions:
   - Secret `LLM_API_KEY`: your API key
   - Variables: `LLM_PROVIDER` (`openai` for any OpenAI-compatible API such as DeepSeek or Qwen, or `anthropic`), `LLM_MODEL` (e.g. `deepseek-chat`), `LLM_BASE_URL` (e.g. `https://api.deepseek.com/v1`)

   Without a key the Action still runs and publishes the stats; only the written summary is skipped.
